# Switchboard

A dispatcher for any fleet, powered by Jev (TypeSafe AI). First wedge: **hospital elevators** — dispatch that understands *what* is waiting (a code team, a bed transport, a visitor), not just *where*.

Built at JEVATHON — Jev Hackathon SF (Sept 26, 2026).
